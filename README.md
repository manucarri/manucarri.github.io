# manucarri.github.io
# Clases Pádel Valencia - Manu Carrilero

Página web oficial para los servicios de entrenamiento y clases de pádel en pista (Valencia y Paterna). Desarrollada en HTML estático y Tailwind CSS.

## 🌍 Arquitectura Bilingüe (ES / EN)

El proyecto cuenta con una estructura de idiomas espejo enlazada mediante etiquetas `hreflang` para SEO internacional:

**Páginas Principales:**
* `index.html` (ES) <-> `index-en.html` (EN)
* `sobre-mi.html` (ES) <-> `about-me.html` (EN)
* `blog.html` (ES) <-> `blog-en.html` (EN)

**Artículos del Blog:**
* `guia-iniciacion-padel.html` <-> `padel-beginners-guide.html`
* `tecnica-tradicional-padel-estancamiento.html` <-> `traditional-technique-padel-stagnation.html`
* `empunadura-continental-padel-errores.html` <-> `padel-continental-grip-mistakes.html`
* `por-que-no-ensenar-contrapared-padel.html` <-> `why-i-never-teach-the-boast-padel.html`
* `formatos-clases-padel-valencia.html` <-> `padel-classes-valencia-group-vs-individual.html`

## ⚙️ Stack Tecnológico
- HTML5 (Semántico y estructurado con Schema.org Local Business)
- Tailwind CSS (vía CDN)
- Lucide Icons
- Alojamiento en GitHub Pages con dominio personalizado

## 📱 Contacto y Reservas
Integración directa con la API de WhatsApp para facilitar la reserva de sesiones y dudas tácticas.
